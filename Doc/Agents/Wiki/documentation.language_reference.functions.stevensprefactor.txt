====== StevensPrefactor ======
;;# 
<color #ed1c24>New in 0.9.1</color>
;;#

###
//StevensPrefactor(k, m)// returns the factor between the Stevens operator and the renormalized tesseral harmonic of rank $k$ and component $m$,
\begin{equation}
O_k^m = \mathrm{StevensPrefactor}(k,m) \, D_{k,m},
\end{equation}
as used by //[[documentation:language_reference:functions:stevenso|StevensO()]]//. The factor makes the polynomial $O_k^m(x,y,z)$, written as the real or imaginary part of $(x + \imath y)^{|m|}$ times a polynomial in $z$ and $r^2$, have integer coefficients without a common divisor and a positive coefficient for the highest power of $z$. It is calculated for any $k$, and depends on $|m|$ only. The definitions are on the page [[documentation:standard_operators:stevens_operators|]].
###

===== Input =====

  * //k// : Integer, the rank, $k \geq 0$.
  * //m// : Integer, the component, from $-k$ to $k$.

===== Output =====

  * A real number, the factor $O_k^m / D_{k,m}$.

===== Example =====

###
The factors for $k \leq 6$, for $m$ from $0$ to $k$.
###

==== Input ====
<code Quanty Example.Quanty>
for k = 0, 6 do
  local line = "k = "..k.." :"
  for m = 0, k do line = line .. string.format(" %12.8f", StevensPrefactor(k, m)) end
  print(line)
end
</code>
